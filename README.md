## Pro 版多出来的东西，按用途拆开看

**次数和格式。** Pro 版不限次压缩。格式方面，免费版覆盖 JPEG、PNG、WebP、HEIC 和 GIF 这几种日常最常见的位图；Pro 版在此基础上多了这些：

- AVIF 和 JPEG-XL（JXL），两种现代高压缩比格式
- TIFF，且是无损模式
- ICNS，Mac 图标文件
- SVG，矢量图也能走压缩流程
- PDF，输出用图时省一步
- APNG 动图

格式转换同样分版本，免费版只能在 JPEG、WebP、HEIC 之间转，转 AVIF 和 JXL 要 Pro。

**自动化。** 这是 Pro 版真正的价值所在。文件夹监控（还能按预设规则压缩）、剪贴板自动压缩、粘贴即压缩、把图片拖到屏幕刘海区触发压缩、Finder 右键菜单、macOS 快捷指令与 AppIntents、带压缩参数的 URL Scheme，全在 Pro 里。免费版虽然也支持 URL Scheme，但没法在链接里指定压缩参数，只能按默认设置处理。

**核对压缩质量。** Pro 版有前后对比视图，滑块一拉就能看压缩后掉了多少细节。免费版没有这个视图，压缩完只能自己打开图看。元数据也在这里分叉：免费版默认保留 EXIF，Pro 版可以配置成删除。如果你要把图片发到公开网页上，原图里的拍摄地点和设备信息带出去不太合适，这一项值得算进去。

**界面上的小事。** 自定义通知样式、隐藏 Dock 图标、压缩后自动复制到剪贴板、压缩预设的集中管理，这些都只在 Pro 里。

还有一个细节值得注意：功能表里写着“所有未来新功能”仅 Pro 可用。这句话的实际含义是，后续版本新增的能力会优先给付费用户，免费版停在现在这个功能集上。

**Zipic 会把我的图片上传吗？**
不会。压缩全程在本地完成，图片不经过服务器，断网也能用。它用的是开源的压缩库，这一点在隐私说明里有写。

**免费版能压哪些格式？**
JPEG、PNG、WebP、HEIC 和 GIF。AVIF、TIFF、SVG、PDF、JXL、APNG 要 Pro 版。

**Windows 版和 Mac 版功能一样吗？**
Windows 版目前是公测，核心压缩能力一致，细节功能可能还在补齐。已经买过授权的直接激活，不用再付钱。

**压缩会不会把图片压糊？**
压缩级别有六档，数字越大压得越狠。日常网页用图在三档左右，肉眼基本看不出差别。Pro 版的对比视图就是用来确认这件事的。

**免费版用久了会自动转成付费吗？**
不会。免费版就是免费版，一天 25 次的上限固定，不会自动扣费。
